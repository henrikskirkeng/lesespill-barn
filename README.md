# Lesestjerner

Et nettbasert, berøringsvennlig lesespill for barn (6–10 år) med:

- 4 nivåer med stigende vanskelighetsgrad
- progresjonssporing med `localStorage`
- stjerner, merker og små belønningstekster
- mobilvennlig design for iPhone og iPad

## Kjør lokalt

```bash
python3 -m http.server 4173
```

Åpne deretter `http://localhost:4173`.
