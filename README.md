# Lesestjerner

Et nettbasert, berøringsvennlig lesespill for barn (6–10 år) med:

- innlogging med brukernavn/passord (lokalt lagret i nettleseren)
- 4 nivåer med stigende vanskelighetsgrad
- nivåvalg der ett nivå må fullføres før neste velges
- progresjonssporing og historikk per profil i `localStorage`
- stjerner, merker og små belønningstekster
- mobilvennlig design for iPhone og iPad

## Kjør lokalt

```bash
python3 -m http.server 4173
```

Åpne deretter `http://localhost:4173`.
